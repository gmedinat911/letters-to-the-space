# Letters to the Space

Static HTML/CSS source for **letterstothespace.com**.

## Structure

- `index.html` — collapsible archive homepage
- `style.css` — shared visual styling
- `letters/*/index.html` — standalone letter pages

## Deployment

Upload the repository contents to the hosting document root (`public_html`). Keep directories at `0755` and files at `0644`. All files are UTF-8.

The prose is canonical content: layout or CSS work should not rewrite, shorten, or paraphrase the letters unless explicitly requested.
